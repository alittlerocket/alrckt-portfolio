Satellite Data Caching

Satellite detection data is critical to our simulations, but computing it slows them down.

I built a system that caches this data locally in highly compressed tables, with constant-time access by geometry and hardware specification.

It improved runtime by over 25% in high-throughput simulations and optimized existing caches by over 80%.

Detection Data Pipeline

Detection data from our simulation engine has to be streamed into a database for downstream services.

I built an asynchronous ETL (Extract, Transform, Load) pipeline that pulls data from the engine's API, converts it into database-ready objects, and loads it with SQL queries. Instances run in parallel, and an LRU cache deduplicates inserts to reduce database load.

Analyzing Satellite Coverage

Our simulation engine rests on assumptions, and how large an area a satellite can cover is one of them.

After studying the physics behind the sensors, I built a tool that lets engineers analyze and tweak satellite parameters to make better-informed decisions.

Machine Unlearning Research:

Machine unlearning removes information from a trained model without retraining it from scratch.

This matters for AI privacy, especially in Europe, where the GDPR gives people a Right to Erasure of their personal data.

I implemented ways to verify the results of unlearning algorithms, such as Fast Unlearning, which maximizes error on the data to forget and then recovers performance by training on other data.
